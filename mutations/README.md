# THE MUTATION WARD

Six new mathematical organisms assembled from the original 73 prompt fragments.

Nothing here treats mathematics as decoration. Every eye, mouth, tongue, material, movement, optical effect, and VHS failure is generated by the governing system. Source components are intentionally reused whenever they acquire a different job inside the new anatomy.

## The surgical rule

The source fragments are not a finite inventory. They are genes:

- **reuse is permitted;**
- **repetition without changed function is not;**
- **the mathematical mechanism must remain visible;**
- **the prop must remain physically imaginable on an overheated 1980s soundstage;**
- **the tape damage must reveal the production history instead of becoming decorative digital glitch.**
