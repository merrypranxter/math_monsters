## How to use this without summoning adjective sludge

1. Begin with one final master prompt.
2. Add only the modular fragments that solve a specific weakness: anatomy, material, optics, camera, motion, or signal damage.
3. Keep the negative prompt attached.
4. If the image becomes a generic neon creature, return to the ontology: build the mathematical pressure first, then allow anatomy to emerge at defects, intersections, branch points, or negative-space intervals.

The complete original transcript and initiating brief are preserved so no useful mutation is lost.
